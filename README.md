# Health Risk Assessor - Backend & Web Interface

An interactive health assessment tool powered by a FastAPI backend machine learning model and a modern dark-mode front-end interface.

## Features
- **Interactive Web Interface**: Form-based risk assessment with dynamic visual feedback.
- **FastAPI REST API**: Validates input metrics and processes risk predictions.
- **Detailed Clinical Breakdown**: Provides indicator risk factors, stress profiles, and next-step recommendations.
